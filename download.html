Verificação de integridade (opcional, mas recomendado)

Depois de baixar, rode o comando abaixo (no sistema em que você está agora) e compare o resultado com o hash SHA256 mostrado acima, na seção de download. Se os dois valores forem idênticos, o arquivo baixado está íntegro.

Linux / macOS — no terminal, na pasta onde está o arquivo:
sha256sum deepin-desktop-community-25.2.0-amd64.iso
Windows — no PowerShell, na pasta onde está o arquivo:
Get-FileHash .\deepin-desktop-community-25.2.0-amd64.iso -Algorithm SHA256

O comando devolve uma sequência de letras e números — é só olhar se bate, letra por letra, com o valor SHA256 mostrado mais acima nesta página. Se for diferente, o download veio corrompido: baixe novamente.

Requisitos recomendados

Confira a configuração de hardware recomendada antes de instalar.

Ver requisitos

Pendrive bootável — Ventoy

Pré-requisito: pendrive com no mínimo 8GB.

  1. Instale o Ventoy a partir do site oficial ou da loja de aplicativos do seu sistema operacional atual.
  2. Abra o Ventoy e selecione o pendrive. Nas opções, recomenda-se o uso do estilo de partição GPT (para sistemas UEFI) e a ativação do suporte ao Secure Boot — este último não é obrigatório.
  3. Clique em "Instalar" para que o aplicativo prepare o dispositivo e o torne bootável.
  4. Copie a imagem ISO do deepin para o pendrive.
Baixar Ventoy
Observação: o Ventoy permite que várias imagens ISO sejam utilizadas no mesmo pendrive, incluindo imagens do Windows. Seu uso não é exclusivo do deepin.
